## 先判断：这次改的是哪一类？

| 改动类型 | 要动什么 |
|---|---|
| **只改基准值 / 改译名**（不动行） | 一处都不用改代码，但要**重算 + 真保存**刷新缓存 |
| **把某个空单元格填上值**（= 给某个武器类别补一条词条） | 同上，**一处都不用改**。洗卡池是 `IsNumeric(数据!<类别列>)` 现场筛的，填上数它自己就进池了（实测：给霰弹补「变焦 80.1」） |
| **加/删普通词条行**（2~34 区） | 全套同步 |
| **加/删融合词条行**（35~52 区） | 全套同步 + 融合表配方 |
| **加新武器 / 改倾向** | 只动「倾向表」，注意 J/K/L 三列和语言位掩码 M |

> 「只改基准值」这一类**不要**直接判断，跑 `源码快照/verify_newbase.py`（真机按钮路径，只在副本上跑）：
> 它会对照 `数据!G:K` 现场算出该类别应有的池子、连点洗卡、并用融合配方验证产物取值。

## 三套正负规则（改数据前确认）

| 规则 | 含义 | 行号 |
|---|---|---|
| **永正** `是永正(k,cat)` | 永不出负面（正面照常出） | **35~52 全类别无条件 True**；近战另加 `{2,3,9,10,11,12,27,29}`；非近战另加 `{9,10,11,12,20}` |
| **永不正** `是永不正(k,cat)` | 正负都不出 | 仅近战 + 35~52 |
| **永负** `是永负(k)` | 只能当负面出 | 仅 `{30}` 概率不获得连击数 |

生成池：正面 `If Not 是永负`，负面 `If Not 是永正`，`是永不正` 两池都先剔。

> 永负 ≠ 永不正：
> 永不正 = 正负都不出；永负 = **只**出负面。

## 计算器 vs 洗卡模拟器：口径不同

| | 计算器 sheet1 | 洗卡模拟器 sheet7 |

## 加新武器的注意点

「倾向表」结构：B 星级 / C 英文 / D 国际服 / E 国服 / F 倾向 / G 类型 / **J 任意叫法索引** / K 倾向值 / L 类别 / M 语言位掩码

⚠️ **J 列和同行 C/D/E 是错开的**：
J 是 C/D/E 的**扁平展开**（`J2=C2, J3=D2, J4=E2, J5=C3 …`）。
**不能拿 J 配同行 G 猜类别** —— 猜错类别，搜索必然不命中。

⚠️ 武器名可能带**尾随 NBSP（ChrW(160)）**，`Trim$` 去不掉，
会导致「锁定失效」（`StrComp` 永不等）。两边比较要同口径用 `净名()` + `压空格()`。
