## 洗卡模拟器 sheet7（v9 版式）

每槽 2 格：属性名格（下拉+手打）+ 数值格（纯数字不带 %），锁定格单列（① 区无）

| 区 | 位置 | 说明 |
|---|---|---|
| ① 开紫卡 | A3:E7，词条 9~12（B:C 名 + D 值） | 按钮 **F4**（CommandButton1） |
| ② 洗卡 | A14:E18，词条 20~23（+E 锁定） | 按钮 **F15**（CommandButton2） |
| ③ 自选洗卡 | I4 搜索 / I5 序号 / I6 武器 / I7 倾向 / **I8 洗卡对象**<br>候选块 9~15（命中行号 O88:O92）<br>词条 18~21（I:J 名 + K 值 + L 锁定） | 按钮 **M24**（CommandButton3） |
| ④ 融合·左 blk2 | 融选 B26 / B27，产物 30~35 行 | 按钮 **F28**（CommandButton4） |
| ④ 融合·右 blk3 | 融选 I26 / I27，产物 30~35 行 | 按钮 **M28**（CommandButton5） |

> ⚠️ **F28 / M28 是单元格位置**，OLEObject 名是 `CommandButton4` / `CommandButton5`。
> `Wps.click()` 要传**按钮名**，传单元格会静默返回 `'no such button'`。

### 下拉池（O:P:Q 列隐藏）

| 池 | 范围 | 格数 |
|---|---|---|
| ①② 正面 / 负面 | `O2:O32` / `Q2:Q32` | 31 |
| ③ 正面 / 负面 | `O35:O65` / `Q35:Q65` | 31 |
| 融合池 | `O68:O75`、`O78:O85` | 8 |

### 关键行为

- **③ 区的池按 I8 构建**：I8 空 → `vcol=0` → 整段静默跳过，读到的是文件里已缓存的取值（不刷新）
- **融合只认卡面上已有的词条**（I18:I21），否则报「所选词条已经不在当前卡面上」
- **产物自动锁定**；每卡最多 1 个融合词条
- 融合消耗两个材料槽，`mo` 先清成「不锁」再**无条件**重滚

### VBA 地址函数

```
卡片格 / 名格 / 数值格 / 锁格
融选格(blk,i) / 融池格 / 融产名格(blk,i) / 融产值格 / 融产锁格
搜索格 / 候选序号格 / 自选武器格 / 洗卡对象格
候选辅助格 / 候选名格 / 候选倾向格 / 候选类别格
```

★ `名格(blk,i)` 和 `融产名格(blk,i)` 的 **i 从 1 起**（产物格 = `I29+i`）
