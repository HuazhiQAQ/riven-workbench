07

口径与词汇

数值是怎么算出来的、哪些词条不会出现、名词都是什么意思。

数值口径

数值公式基准值 × 组合系数 × 倾向 × 浮动
理论值口径÷ 9 ×(1 + 等级)，满级时两者相等

连击类（初始连击 / 连击持续时间 / 额外连击数几率 / 概率不获得连击数）与攻击范围是近战专属，远程武器的池里不会出现；「概率不获得连击数」只能当负面出。

冲击 / 穿刺 / 切割三条只看武器伤害构成里有没有这一类型：没有就不出现对应物理词条（01 倾向／区间表照常列出、数值格填 - - - 灰显；02 词条下拉与 03 开卡洗卡直接不进池）。元素词条没有这条限制：十种元素在任何武器上都能洗出。

词汇表

紫卡 / Riven带随机词条与随机数值的武器 Mod，词条组合与数值都可重洗
倾向 (Disposition)直接乘在数值上的系数，全库武器统一 各武器有自己的数值（默认 ）；计算器里可手填别的值（如最后时光的武器倾向表里的存档值）做对比
基准值「数据」表里某个词条在某个武器类型下的原始系数，是整套计算的起点
组合系数2增益0减益 / 2增益1减益 / 3增益0减益 / 3增益1减益 四种，增益与减益各有一个系数
浮动0.9 ~ 1.1 之间的随机乘数，决定同一张卡洗两次数值不一样
融合把卡面上两条词条换成一条融合词条。换的只是词条，数值按同一套公式算（浮动不重新随机，取两个材料里较高的那个）；一张卡最多带一条
永正 / 永负永正＝只当正面出（融合词条、元素伤害等）；永负＝只当负面出（概率不获得连击数）
空基准值这类武器根本没有这条属性（如步枪没有初始连击），空格不是 0，直接不进词条池
物理词条冲击 / 穿刺 / 切割只在武器自带该类型伤害时可洗出。这是与「空基准值」并列的第二种「洗不出来」：空基准值＝这类武器没有这条属性，物理词条＝属性存在、但这把武器的伤害里没有它
本体 / 变体本体＝能开出自己那把紫卡的武器；变体＝同族衍生版（Prime / 赤毒 / 信条 / 棱晶 / 亡魂 / 破坏者 / 组合枪另一形态…）。变体装本体紫卡，卡名仍是本体的名字
派系伤害对科普斯 / 克隆尼 / 异变体 / 奥罗金 / 科腐者 / 炽蛇军。表里 1.45 是倍率（＝+45%＝伤害变 1.45 倍），按 ×1.45 显示
武器后坐力方向相反的一条：正面槽是武器后坐力降低（显示 −90%，好事），负面槽是武器后坐力增加（显示 +44%，坏事）
对中差值当前数值相对理论中值的偏离；正面取 当前÷中值−1，负面取 1−当前÷中值
理论最小 / 中值 / 最大把浮动取 0.9 / 1.0 / 1.1 算出的区间在当前等级下的值
锁定重洗时原样保留该词条，并冻结整张卡的组合类型
历史倾向这把武器在倾向变动还在时自己的倾向值，收在最后时光的武器倾向表里；计算器选武器时自动填进「对比历史倾向」，用来和当前生效的 该武器自己的 对照
